清晨临窗晨课，午后习武练艺，黄昏静坐悟道，夜里翻一卷藏书阁的诗——**一日五段修行**，日拱一卒，看属性一点点涨起来，看藏书一点点厚起来。春樱、夏荷、秋枫、冬雪在背景里轮转，晴雨风雪落进笔下。

## 📜 核心玩法

- **起名即入江湖** — 只需取一个侠客名，无需任何冗杂设置，一步踏入。
- **今日修行** — 每日五段：**晨课 · 技艺 · 武学 · 悟道 · 江湖事**。「江湖事」中暗藏抉择，不同选择牵动属性成长。
- **属性与评价** — 文武、心境、人脉、声望随修行积累，并给出阶段性评价，看见自己的来路。
- **自创人设** — 自定义侠客形象文案，上传专属画像，江湖里住着一个你想要的自己。
- **藏书阁** — 诗词与典籍随修行逐渐充实，随时翻阅，温故而知新。
- **个人界面** — 查看身份体验、藏书阁，上传背景音乐与侠客画像，江湖由你布置。
- **四时气象** — 春樱夏荷秋枫冬雪，晴雨风雪配粒子与山水背景，江湖自有寒暑。

## 🌐 部署到 GitHub Pages

仓库根目录即站点根目录。已对 `main` 分支启用 GitHub Pages：

> Settings → Pages → Source: *Deploy from a branch* → Branch: `main` → `/root`

推送后等待数秒，站点即自动构建上线。
