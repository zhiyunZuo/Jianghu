# 江湖侠客成长模拟器

水墨风文字养成小游戏。取一侠客名，入此江湖；七种身份皆可历，每日修行、自创人设、藏书阁相伴，于晨昏四季间慢慢成长为一代侠客。

> 在线试玩：**https://zhiyunzuo.github.io/Jianghu/**

## 玩法

- **起名入江湖**：只需取一个侠客名，便踏入江湖，无需其他设置。
- **七种身份**：江湖游侠、世家弟子、书院学子、医者、琴师、剑客、隐士——随时切换体验，各有专属加成与修行内容。
- **今日修行**：每日五段——晨课、技艺、武学、悟道、江湖事。江湖事中会有抉择，不同选择影响属性成长。
- **属性与评价**：文武、心境、人脉、声望等属性随修行积累，并给出阶段性评价。
- **自创人设**：可自定义侠客形象文案，并上传专属画像。
- **藏书阁**：收录诗词与典籍，随修行逐渐充实，可随时翻阅。
- **个人界面**：查看身份体验、藏书阁、上传背景音乐与侠客画像。
- **季节与天气**：春樱、夏荷、秋枫、冬雪与晴雨风雪，配粒子与山水背景，江湖自有四时。

存档保存在本机浏览器，随开随玩。

## 本地运行

```bash
# 在项目根目录起一个静态服务器
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/index.html
```

也可直接双击 `index.html` 游玩（纯静态站点，无需服务器）。

## 部署（GitHub Pages）

仓库根目录即站点根目录，已对 `main` 分支启用 GitHub Pages：
Settings → Pages → Source: Deploy from a branch → Branch: `main` → `/root`。

## 目录结构

- `index.html` — 页面骨架与视图
- `css/style.css` — 水墨主题样式
- `js/images.js` — SVG 水墨插图
- `js/data.js` — 通用数据（身份、季节、天气、诗词…）
- `js/data-relations.js` — 江湖结交数据
- `js/data-identity-cultivation.js` — 七身份专属修行内容
- `js/app.js` — 应用逻辑

## 技术说明

纯原生 HTML / CSS / JavaScript，无构建步骤、无第三方依赖。所有数据内置，开箱即玩。
